# 资产库

> 跨项目聚合素材的全局页面（`/assets`），并支持**不归属任何项目**的独立素材。

---

## 一、三个分区

顶部导航的 **资产库** 入口，按用户视角分为四个视图：

| 分区 | 内容 | 对应数据库类型 |
|---|---|---|
| 人物图 | 角色设定图 / 定妆图 | `CHARACTER` |
| 场景图 | 场景图 | `SCENE` |
| 音频 | 配音 / 配乐 / 音效 | `VOICE` + `MUSIC` + `SFX` |
| 全部 | 以上全部（含 image / video） | — |

> **分类是「多对一」**：用户视角的分组与数据库的 `AssetType` 不是一一对应，
> 映射定义在 `services/assets.py::ASSET_GROUPS`。这样界面可以按人的理解组织，
> 而不用改数据模型。

支持：按归属项目筛选、关键词搜索、**仅看独立素材**。卡片上显示归属项目。

---

## 二、独立素材：`project_id` 可为空

**为什么需要**：在资产库里直接合成一段语音（比如做片头念白），它不属于任何项目。
如果强制挂在某个项目下，既污染项目列表，又会随项目删除而消失。

**所以**：`assets.project_id` **可为空**。空值表示"不属于任何项目的素材"。

- 落在 `storage/{类型}/_library/`，与真实 `project_id` 目录**隔离**
- 不会被 `purge_project` 的整目录清理误伤
- 序列化结果里 `project_id` 为 `null`，前端显示为「独立素材」

数据库迁移：`database.py::_DROP_NOT_NULL` 里登记 `("assets", "project_id")`，启动时自动解除 NOT NULL。

## 三、生成语音

资产库的**音频分区**可直接合成语音并保存：

```
填文本 → 选音色（Tingting / Meijia 等快捷 chip）→ 调语速 → 生成并保存
```

产物直接进素材库，**归属项目可选「不归属」**，即成为独立素材。

也可以走 HTTP：

```bash
curl -X POST http://127.0.0.1:8077/api/assets/generate/voice \
     -H 'Content-Type: application/json' \
     -d '{"text":"这是一段独立语音。","voice":"Tingting"}'
```

返回 `{ ok, data: { asset_id, name, duration, provider, model, project_id: null, url } }`。

> 音色列表**从后端读**（`GET /api/settings/voices` 返回 `engines[].speakers`），
> 前端不硬编码任何音色名。

## 四、API

```
GET    /api/assets                    列表
       ?group=character|scene|audio|image|video|all
       &project_id=...       按归属项目筛选
       &unassigned=true      只看独立素材
       &keyword=...          关键词
       &type=VOICE           按数据库类型（精确）
GET    /api/assets/{id}               详情
DELETE /api/assets/{id}?confirm=true  删除
POST   /api/assets/generate/voice     生成独立语音
GET    /api/settings/voices           可用音色与曲风
GET    /api/settings/providers        模型设置
```

列表返回里带 `stats.groups`，给出各分区的数量与体积。

## 五、每个产物都记录来源

`Asset` 记录的元数据：`prompt` / `negative_prompt` / `model` / `provider` / `workflow` / `parameters` / `seed` / `duration` / `format` / `size_bytes`。

**为什么**：AI 生成**不可复现**（随机种子）。你今天跑出一个满意的镜头，明天想再要一个一模一样的，做不到。记录是唯一能"回到某个好结果"的方式。

> 这也是[核心概念](核心概念#06--每个产物都要能说清我是怎么来的)第 06 条的落地。

成片同理 —— 每次合成都是一版，历史版本可**切换预览、标记当前生效版、并排对比、逐版下载**（`GET /api/projects/{id}/outputs`）。

## 六、Web UI 的对应位置

| 页面 | 内容 |
|---|---|
| 资产库（`/assets`） | 全局跨项目素材 + 语音生成 |
| 项目详情 · 素材 | 该项目下的素材，按类型过滤 |

| 项目详情 · 成片 | 主播放器 + 历史版本列表 |

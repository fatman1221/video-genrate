# 模型引擎与配置

> 三类模型（生图 / 图生视频 / 语音生成）各选一个引擎，改完**立即生效、重启后依然保留**。

---

## 一、三类设置项

在 Web UI 的 **「系统设置」** 页，或走 Skill / HTTP：

| 设置项 | 可选引擎 |
|---|---|
| 生图模型 | 本地渲染引擎 / ComfyUI / 云端 API |
| 图生视频模型 | 本地渲染引擎 / ComfyUI / 云端 API |
| 语音生成模型 | 本地 TTS（macOS say）/ 云端 TTS |

每组可填**模型名**与**连接凭证**（Base URL / API Key）。云端 API Key 只以掩码（`••••1234`）回显，不返回明文；留空表示不修改。

---

## 二、全部 Provider 一览

每类能力都有独立注册表，可运行时切换，**业务层零改动**：

```
image        local(PIL 漫画分镜)   | comfyui | cloud
video        local(关键帧+ffmpeg运镜) | comfyui | cloud
tts          local(macOS say)     | cloud
music        local(lavfi 和弦垫)   | cloud
sfx          local(lavfi 合成)
subtitle     local(SRT/ASS/VTT)   | cloud_asr
enhance      ffmpeg(超分/补帧/降噪/锐化/调色)
processing   ffmpeg(拼接/裁剪/混音/烧字幕/合成/封面)
browser      agent_browser(登记任务 + playbook)
```

共 **17 个 Provider 实例 / 9 类能力**。

## 三、配置的存放与生效顺序

| 层 | 位置 | 说明 |
|---|---|---|
| 1 | `providers` 表（`is_default` / `config.model` / `config.credentials`） | **用户设置，唯一真相来源**，启动时恢复 |
| 2 | 环境变量（`backend/.env`） | 首次运行的默认值，被用户设置覆盖 |
| 3 | 代码默认值 | 兜底 |

**关键实现**：Provider 实现**每次调用时**才向 `providers/runtime.py` 查询连接信息，所以设置页改完**立即生效，不需重启**。

- `sync_providers_table()` 每次启动只刷新「代码侧派生字段」（名称 / 能力 / 可用性），**不会覆盖**用户的默认引擎、模型名与凭证
- 云端 API Key 只以掩码（`••••1234`）回显，不返回明文

> **一个真实反例（已修）**：早期版本 `set_default_provider` 只改内存注册表、**不落库**，
> 重启就把用户选择丢了；且 `sync_providers_table()` 每次启动覆盖 `is_default`，
> 会再冲一次。这类"看起来能用、重启就没了"的设计是最隐蔽的坑。

## 四、切换默认引擎

```bash
# 切到 ComfyUI 做图生视频
curl -X POST http://127.0.0.1:8077/api/skills/set_default_provider/invoke \
     -H 'Content-Type: application/json' -d '{"kind":"video","name":"comfyui"}'

# 同时设定模型名与云端凭证
curl -X POST http://127.0.0.1:8077/api/skills/set_default_provider/invoke \
     -H 'Content-Type: application/json' \
     -d '{"kind":"tts","name":"cloud","model":"cosyvoice-v2",
          "credentials":{"base_url":"https://...","api_key":"sk-..."}}'
```

## 五、接入 ComfyUI（出图 / 图生视频）

在「系统设置」或 `backend/.env` 填 ComfyUI 地址（默认 `http://127.0.0.1:8188`）即可。

推荐用**工作流模板**机制 —— 把一大坨工作流 JSON 变成**有名字的模板**：

```bash
# 列出可用模板
curl -X POST http://127.0.0.1:8077/api/skills/list_image_workflows/invoke \
     -H 'Content-Type: application/json' -d '{}'

# 出图时指定模板名
curl -X POST http://127.0.0.1:8077/api/skills/generate_image/invoke \
     -H 'Content-Type: application/json' \
     -d '{"shot_id":"shot_xxx","provider":"comfyui","workflow_name":"qwen_image_scene"}'
```

### 仓库内置的模板

| 模板 | 用途 |
|---|---|
| `qwen_image_scene` / `qwen_image_character` | Qwen-Image 2.1 出场景图 / 角色定妆图 |
| `qwen_edit_scene` | Qwen-Image-Edit「参考图 + 提示词」编辑，用于**角色一致性关键帧** |
| `minimax_h3_i2v` | MiniMax H3 图生视频（本地关键帧 → 真运动镜头） |
| `sdxl_ipadapter_scene` | SDXL + IPAdapter 备选（中文提示词理解较弱，保留） |

### 占位符

| 占位符 | 说明 |
|---|---|
| `{{prompt}}` | 正向提示词 |
| `{{negative_prompt}}` | 负向提示词 |
| `{{width}}` / `{{height}}` | 分辨率（**保持 int**，ComfyUI 不接受字符串） |
| `{{seed}}` | 随机种子（同样保持 int） |
| `{{image}}` / `{{frames}}` | 参考图 / 帧数（视频模板用） |

> **关键实现细节**：当某个值**整个字符串**就是 `{{key}}` 时，替换后保留原始类型；
> 若 `{{key}}` 内嵌在长字符串里，则做文本替换、结果为字符串。
> 这解决了 ComfyUI 对 `width` / `seed` 必须为数字的硬要求。

### 模板的选择优先级

出图时按三级决定用哪个模板（`handlers._resolve_workflow_name`）：

1. **单次调用**指定 —— `workflow_name` 参数
2. **项目级**固化 —— `set_image_provider` 写入项目 `extra`
3. **全局默认** —— `backend/.env` 的 `COMFYUI_WORKFLOW_CHARACTER` / `COMFYUI_WORKFLOW_SCENE`

人物图取 `character` 模板，场景图取 `scene` 模板。

### 新增自己的模板

把 **API 格式**工作流丢进 `backend/app/workflows/templates/`，在需要变化的地方写占位符即可。

导出方法：ComfyUI 里 **Workflow → Export (API)**，然后手工把 prompt / seed / 尺寸替换成 `{{...}}`。

也可以在 `backend/.env` 设 `COMFYUI_WORKFLOW_DIR=<目录>` 指向外部目录 —— 同名模板会覆盖内置模板，**适合放本机专属、不便入库的工作流**。

> 换成自己的工作流**只需替换 JSON，无需改代码**。
> 改动模板后需**重启后端**（模板是进程内缓存的）。

## 六、批量出图 CLI

```bash
# 自检：后端 / ComfyUI / 工作流模板 / Provider 四项
python scripts/gen_images.py doctor

# 建项目并固化出图配置
python scripts/gen_images.py init --name "我的短剧" --style "写实电影感，自然光"

# 人物图
python scripts/gen_images.py character --project proj_xxxx \
    --name "林知夏" --appearance "22岁女生，齐肩黑发，米色针织衫" --seed 8888

# 场景图
python scripts/gen_images.py scene --project proj_xxxx \
    --title "图书馆清晨" --prompt "清晨的大学图书馆，阳光从高窗斜射，尘埃在光柱中漂浮"

# 批量（json 清单见 examples/shots_example.json）
python scripts/gen_images.py batch --project proj_xxxx --file examples/shots_example.json
```

## 七、排错

### `ComfyUI 提交失败: 400`

错误已被解析成可读格式：

```
节点 1(UNETLoader): value not in list: 'xxx.safetensors' not in [...]
```

**含义**：模板里的模型文件名在本机不存在。核对：

```bash
curl -s http://127.0.0.1:8188/object_info | python -c "
import json,sys; d=json.load(sys.stdin)
print(d['UNETLoader']['input']['required']['unet_name'][0])"
```

### `工作流模板不存在：xxx`

模板名拼错，或文件不在 `backend/app/workflows/templates/`。
用 `list_image_workflows` 或 `python scripts/gen_images.py doctor` 查看可用模板。

### `ComfyUI 生成超时或无输出`

本地首个任务含加载模型（int8 量化模型 + 31B 文本编码器），可能较慢。
默认超时 `COMFYUI_TIMEOUT=1800` 秒，可调大。

### 设置里显示"不可用"

- **ComfyUI**：会额外探测 `8188` 端口是否在线；服务没起就显示不可用
- **云端**：需要 Base URL + API Key **都填了**才 ready
- **本地**：取决于引擎是否存在（如 macOS `say`）

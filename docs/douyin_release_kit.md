## 0. 先说三个硬约束（不看这段会白做）

### ① AI 标识是硬性合规，不是可选项

中央网信办 2026 年要求短视频平台提供 **6 类「必选标签」**，发布者**必须选一项才能发出去**：

| 必选标签 |
|---|
| 含有虚构演绎内容 |
| 含有 AI 生成内容 |
| 含有营销信息 |
| 内容为转载 |
| 内容为个人观点 |
| 无需标注 |

**本片怎么选**：核心选 **「含有 AI 生成内容」**（画面、配音全部 AI 生成）；本片同时是虚构剧情，如发布页允许叠加或需补标，再补 **「含有虚构演绎内容」**。

抖音侧的额外动作：
- 发布页**必须勾选「AI 生成」**选项 → 平台自动加统一水印 + 显式标识。
  **不勾选会直接触发限流，且是机器判定、没有人工审核给你解释的机会。**
- 视频类还要**封面标注「AI 生成」**，并在**开头 3–5 秒全屏显示标识（持续 ≥5 秒）**，或播放全程角落固定显示。
- 别抹元数据。抖音有 AI 内容元数据读写功能，删了也会被检测出来补标。

> 结论：本片开头已经有「2147 · 深空守望者空间站」的字幕卡，**建议在镜 01 的字幕卡上直接加一行「AI 生成」小字**，5 秒后淡出。这样既满足开头全屏标识，又不破坏片头质感。

### ② 横屏 5 分钟，是抖音的天然逆风局

- 抖音是竖屏平台，标准是 **9:16 / 1080×1920**。
- **16:9 横屏直接发会被加黑边**，黑边视频的完播率明显偏低，直接影响推荐权重。
- 抖音**建议时长 15–60 秒**；新账号更应先跑短时长高完播，权重起来后再拉长。
- 本片 301 秒，完整看完的比例会很低——**完播率是抖音分发的第一指标**。

**三个可选方案：**

| 方案 | 做法 | 适合 |
|---|---|---|
| **A. 竖屏精华版（推荐）** | 从 33 镜里挑 8–10 个最强镜头，重新按 9:16 构图，剪成 **60–75 秒**，结尾 3 秒带正片引导 | 抖音主推、涨粉 |
| **B. 正片直发** | 就用现在的横屏成片，配下面「版本 A」文案 | 作品展示、沉底长尾 |
| **C. 双发** | 竖屏精华版发抖音，5 分钟正片发 B 站/视频号，抖音简介挂引导 | 全平台铺开 |

> 方案 A/C 我可以直接做：本地有 ffmpeg 和 33 镜全部素材，**不用重跑任何 AI 视频**，只做重构图 + 剪辑 + 重新烧字幕。
> 竖屏重构建议用「中心裁切 + 上下留白」而不是模糊背景填充——本片画面构图偏空，中心裁切丢的内容最少。

## 3. @ 谁（这是你问的重点）

### 先说个实话

抖音的 `@` 是**站内账号引用**，必须对方账号真实存在，而且**@ 官方大号基本不会带来流量**——大号不会因为被 @ 就转发你。真正带流量的是**话题标签**和**完播率**。

所以 @ 的作用是**「署名 + 技术归属」**，让人一眼看出你用了什么、出自哪里。按这个定位来用。

### 建议 @ 的（注明技术归属）

| 建议 @ | 说明 | 备注 |
|---|---|---|
| `@海螺AI` | MiniMax 官方品牌就是**海螺AI**（hailuoai.com），不是"MiniMax"这个名字 | **你在抖音内先搜一下确认蓝V**，账号名可能是「海螺AI」或「MiniMax」 |
| `@通义千问` | 阿里 Qwen 的官方品牌名 | 抖音搜「通义千问」确认 |
| `@WorkBuddy` | 你的 Agent 调度工具 | 如站内搜不到官方号，就写成纯文本「WorkBuddy 调度」不 @ |

> **操作建议**：发布页里先输 `@` 看联想列表，**能联想出来的才是真账号**。联想不出来的，就别写 @，改成正文里的纯文本提及，否则会显示成一段没链接的普通文字，反而难看。

### 不要 @ 的

- ❌ 影视/科幻类大 V、影视剪辑号 —— 无意义，还可能被判营销导流。
- ❌ 一次 @ 超过 3 个 —— 抖音会降低分发权重。

### 话题标签（真正的流量入口，3–5 个最佳）

**主推组合（4 个）**
```
#AI短片 #科幻短片 #归途信号 #AI创作
```

**冲量组合（加 1–2 个热点大类）**
```
#AI短片 #科幻 #AI创作 #深空 #人工智能
```

**技术向组合**
```
#ComfyUI #AI视频 #本地部署 #通义千问 #AI短片
```

> 标签别超过 5 个，堆砌标签会被判定低质。前 2 个最重要，放最想被分发的词。
